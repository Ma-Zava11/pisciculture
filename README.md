
# Pisciculture intelligente

Système IoT et IA pour la surveillance de la qualité de l'eau
et le suivi de production piscicole multi-bassins.

## Technologies
- ESP32 / Arduino
- React.js / Vite
- Python / FastAPI
- PostgreSQL
- Scikit-learn

## Fonctionnalités prévues
- Gestion des bassins, espèces et lots
- Surveillance température, pH et oxygène dissous
- Suivi des effectifs, alimentations et pesées
- Alertes et prédiction des risques
